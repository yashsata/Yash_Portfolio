# Yash Sata Portfolio

A responsive portfolio for AI Director / AI Artist Yash Sata, built with
Next.js, React, TypeScript, Tailwind CSS, and optimized YouTube embeds.

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production check

```bash
pnpm lint
pnpm build
pnpm start
```

The downloadable resume is stored at `public/Yash-Sata-Resume.pdf`.
